AUTOCRATE

AutoCrate ✕ Zoo.dev

Automatic shipping crate generation for oversized industrial machines.

Drop in the STEP file of a machine. AutoCrate measures its real envelope, dimensions a crate around it, builds that crate as true b-rep geometry in the Zoo Engine, and names the transport gauge that will carry it. When no single crate fits, it splits the shipment along planes that follow the engineering breakdown, and never cuts a body in two.

How it works

Measure the real envelope

A convex hull and a yaw sweep find the tightest footprint, not the axis aligned bounding box of the CAD file. Unit and up axis are inferred from the geometry, and can be overridden when the guess is wrong.

Build a crate, not a box

Skids, floor, studs, panels and blocking are dimensioned from the envelope and the gross mass, then built as real solids in the engine. The crate is what gets checked against the gauge, never the bare machine.

Split when nothing fits

Cutting planes are searched across every allowed pose. A body that straddles a plane travels whole with the group above it. The tool proposes and prices the split. Engineering decides.

Zoo APIs used

  • File Format API

    create_file_conversion_options get_async_operation

    The customer's STEP file is converted to a mesh through the asynchronous route and polled to completion. The synchronous variant times out past a minute, whatever the file size.

  • Engine API · modeling session

    start_path move_path_pen extend_path close_path extrude

    A single WebSocket carrying MessagePack. Every skid, stud, panel and block is sketched and extruded into a b-rep solid, not approximated by a mesh.

  • Engine API · scene assembly

    import_files set_object_transform object_set_material_params_pbr modeling_cmd_batch_req

    The machine is imported as b-rep and placed at exactly the pose the study computed, so one STEP file holds the machine and its crate together. Blocking is coloured engine side, and commands travel in batches.

  • Engine API · export

    export set_scene_units default_scene

    STEP for the crate maker's PLM, glTF for the viewer, both with explicit units and coordinate handedness so nothing arrives lying on its side.

  • Text-to-CAD API

    create_text_to_cad

    Generated the demo machine shipped with the repository. It is the one model whose licence is ours, which is why the demo runs offline with no third party CAD.
